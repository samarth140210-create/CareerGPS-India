# CareerGPS India

CareerGPS India is an AI-powered career guidance platform designed to help Indian students discover suitable careers, identify skill gaps, find colleges, scholarships, competitions, and receive personalized guidance through an AI mentor.

---

## Features

### Student Features

- User Registration & Login
- Career Assessment Tests
- AI Career Matching
- Personalized Career Roadmaps
- Skill Gap Analysis
- College Recommendations
- Scholarship Recommendations
- Competition Recommendations
- AI Mentor Chatbot
- Progress Dashboard

---

### Admin Features

- User Management
- Assessment Management
- Analytics Dashboard
- Platform Monitoring
